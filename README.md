> **Trace's copy of the KiCad project and worksheet template library.** [Trace](https://buildwithtrace.com) is an AI hardware design tool built on KiCad: describe the device you want in plain words, and Trace designs the circuit board and a 3D-printable case for it, checks the design and helps you order the board. Trace uses this library. The library itself comes from the [KiCad project](https://gitlab.com/kicad/libraries/kicad-templates); to contribute to it, follow KiCad's guidelines below and contribute upstream. New to electronics? Start with [How to design hardware with AI](https://buildwithtrace.com/design-hardware-with-ai).

# KiCad Templates

This repository contains the official KiCad project and worksheet templates.

Contribution guidelines can be found at http://kicad.org/libraries/contribute
The library convention can be found at http://kicad.org/libraries/klc/

Other KiCad library repositories are located:

* Symbols: https://gitlab.com/kicad/libraries/kicad-symbols
* Footprints: https://gitlab.com/kicad/libraries/kicad-footprints
* 3D Models: https://gitlab.com/kicad/libraries/kicad-packages3d
